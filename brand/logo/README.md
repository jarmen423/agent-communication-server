The Agent Communication Server mark: two overlapping speech bubbles with the server as the lens between them.

- `mark-light.svg`: full colour for light grounds. Teal `#0f7c74`, orange `#d9731a`, lens `#171a21`.
- `mark-dark.svg`: full colour for dark grounds. Teal `#3cb8ab`, orange `#f5a742`, lens `#eef0ea`.
- `mark-mono.svg`: single ink `#171a21`, lens knocked out to the ground. For one-colour use.

All three are 64-unit SVGs that scale cleanly down to 16px.
